# Smart City Pilot Policies and Carbon Emissions in China

An empirical research project examining the impact of China's smart-city pilot policies on urban carbon emissions.

## Project Overview

This project analyzes 71,316 observations to evaluate whether smart-city pilot policies contribute to carbon-emission reduction and to identify the underlying mechanisms.

## Research Question

- Do smart-city pilot policies reduce urban carbon emissions?
- How do energy efficiency and public transportation contribute to the policy effect?

## Methodology

- Data cleaning and feature engineering
- Statistical and policy-effect analysis
- Machine-learning analysis
- Robustness and mechanism tests
- Geospatial and statistical visualization

## Tools

- Python
- R
- Stata
- ArcMap
- Origin

## Key Findings

The results suggest that smart-city pilot policies can reduce carbon emissions, primarily through:
- Lower energy-consumption intensity
- Increased use of public transportation
- Improved urban resource allocation
